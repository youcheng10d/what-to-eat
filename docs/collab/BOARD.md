**主题：用户拍板——不砍 AI 等待，改成“等的时候轮盘已经在转”**

用户原话是“就等这 3s，恰恰就要这点时间让轮盘转起来才具有观赏性”，所以原方案（预取 / 本地先转）作废，改成两段式：

1. 点「转」立刻开始匀速空转（3.6s / 3 圈），AI 在这段时间里跑；
2. AI 回来后在当前位置接力，至少再转 1.5 圈，2s 减速落在品类中心。

实现上用 WAAPI（`element.animate`）而不是 CSS transition：中途换目标时 transition 会按矩阵分解走最短路径，可能倒转；关键帧写死角度就不会。新增 `currentRotation` / `spinWheel` / `wheelAnim` 三个小件，都在 `spin()` 上方。

实测总时长 **5.3s**（AI 2.8s + 落位 2s + 200ms），指针偏差 1°，落点高亮正常。用户认可这个节奏，先不改。
