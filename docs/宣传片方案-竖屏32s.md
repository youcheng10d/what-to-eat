# 吃嘛 · 竖屏宣传片方案（v2.3.2）

> 用途：抖音 / 视频号 / 答辩暖场。30–35 秒，竖屏 1080×1920，纯代码渲染 + 真实截图，不用 TTS。
> 承接已完成的 8 秒开场（`D:\Github\video-showcase\projects\chima\deliver\吃嘛-开场8s.mp4`，橙光白主题）。

## 一、定位

| 项 | 值 |
|---|---|
| 时长 | 32 s（8 s 开场复用 + 24 s 正片） |
| 画幅 | 1080×1920 竖屏，30 fps |
| 渠道 | 抖音 / 视频号 / 比赛暖场 |
| 声音 | 纯配乐 + 画面字幕，**不用 AI 配音**（用户已否决人机音色） |
| 主题 | `claude-light` 橙光白（与已有开场一致） |
| 节拍 | 120 BPM，1 拍 0.5 s，正片每 4 拍切一次 |

**一句话立意**：不是"又一个推荐工具"，是"食堂门口那 30 秒，替你少纠结一次"。

## 三、文案（全部走画面字幕，不配音）

开场三句沿用已完成版本：

1. 每天这个点，你都卡住
2. 两千五百八十二道菜，吃哪个
3. 吃嘛

正片字幕（短句，每句 ≤12 字）：

- 说一句话就行
- 减肥、预算 15、不想吃辣
- 它给你三样东西：多少钱、多少卡、去哪吃
- 不想重样，就换个口味
- 两个食堂，两千多道真实菜品
- 说一句，替你把今天这顿定了

> 说明：不再使用"治愈你的胃""干饭人冲"这类文案，理由与产品内一致——不可验证的情绪句会削弱可信度。

## 四、给渲染器的提示词（逐段）

> 渲染方式：`video-showcase/templates/render-segment.mjs`，每段一个 HTML，`renderFrame(t)` 为纯函数。以下每条可直接作为写页面的指令。

**S1 首页点亮**

```
1080×1920，橙光白主题。背景 #fbf3e7 纸面质感，中央放 01-home 截图（宽 78%），
输入框位置叠一层 2px 橙色描边，随时间做 2 拍呼吸（透明度 0.55→1，缩放 1→1.02）。
左上角深墨胶囊：「01 / 一句话」。右下角细线倒计时 4 拍。
```

**S2 逐字输入**

```
同主题。截图不动，在输入框内用等宽字体逐字输出「减肥、预算15元、不想吃辣」，
每 0.18 s 一个字，末尾光标闪烁 2 次。文字为 #c2410c，字号 42px。
```

**S3 按钮按下**

```
截图放大到 1.06 并向下位移 60px，让「替我决定！」按钮位于画面中心。
按下瞬间：白闪 0.12 s，按钮缩放 1→0.94→1，环形冲击波一圈，半径 0→320px，透明度 0.6→0。
```

**S4 数据三连**

```
结果卡占满画面 82%。依次点亮三个数据点，每个停留 2 拍：
¥9.9（价格）→ 400 kcal（热量）→ 三食堂一楼（档口）。
点亮时该行向上浮 6px、描边 2px 橙色、其余区域压暗到 0.72。
```

**S5 换口味 / 三卡**

```
三张卡横向排列，整体倾斜 -6°，每张延迟 70ms 依次入场（translateY 40→0，opacity 0→1）。
中间卡顶部浮出绿色标签「换个口味·清淡」，标签做一次弹性 1→1.12→0.97→1。
```

**S6 数据大字卡**

```
底色切深墨 #2b1a10。三组数字从左到右跳表：
2 个食堂 / 2382 道菜 / 65 个档口。
数字用 Noto Sans SC 900，字号 240px，颜色 #fbf3e7，关键词用 #c2410c。
背景铺 40px 网格线，透明度 0.06，随数字落定整体推镜 1→1.04。
```

**S7 落版**

```
回到橙光白。中央「吃嘛」两字 320px 砸入（缩放 1.6→1，模糊 14→0，0.12s）。
下方一行小字：说一句，替你把今天这顿定了。再下方：youcheng10d.github.io/what-to-eat
底部留 200px 安全区（抖音界面遮挡）。最后 0.6 s 整体淡出到 0.9 亮度。
```

## 六、制作步骤（在 D:\Github 内完成）

1. 在 `video-showcase/projects/chima/segments/` 新建 `s1.html` … `s7.html`，复用 `templates/common.js` 的缓动与卡点冲击
2. 每段先用 `--still` 出 5 张静帧，拼接触表确认构图，再整段渲染
3. `ffprobe` 校验每段帧数（时长×30）
4. 把 8 s 开场与 7 段拼接，`concat` 后混音；配乐延续 `synth_opening.py` 的 120 BPM，第 6 段做 drop-out
5. 质检：抽 1 fps 接触表、检查 32.00 s / 960 帧 / 无黑帧 / 峰值 -0.6 dBFS
